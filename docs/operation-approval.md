# 操作批准

普通 Agent 的发送栏左侧提供三种模式，选择按会话保存在桌面 Runtime 数据库中：

- 始终需要批准：等待用户选择允许或拒绝。
- 帮我批准：由背景任务中选择的模型判断，允许则执行，否则等待用户选择。
- 无需批准：直接执行。

所有终端启动和终端输入，以及文件工具的工作区外访问进入同一个批准入口。
工作区内读取、搜索、新增、修改和删除不需要批准。显式添加的附件可以直接读取。
修改前读取、补丁校验和文件有效性检查仍然适用。
Multi-Agent 固定直接允许，不调用批准模型，不产生人工批准请求。

批准卡片位于输入框上方，不进入消息滚动区。每次允许只授权当前操作。
只有批准模型返回的说明会作为风险提示展示；模型失败、异常响应或正常请求超时均转人工批准。
模型请求仅包含用户本轮目标、操作和必要的执行环境，不携带完整历史或调用工具。

待批准请求由 Electron Runtime 持有，客户端通过受限 IPC 获取状态及回复。
停止任务会取消待批准操作；迟到的模型结果或用户回复不会恢复执行。
应用重启不会恢复待批准操作，原任务遵循既有 Runtime 中断恢复流程。
终端授权在获取协作写锁之前完成，并在实际终端执行入口再次校验。

这属于应用层批准机制，不是操作系统沙箱。无需批准模式和 Multi-Agent 模式可以执行外部操作。
